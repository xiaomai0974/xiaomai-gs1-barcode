# 小麦 GS1 条码生成器

在浏览器本地生成 GS1-128、正方形 GS1 DataMatrix、EAN-13、Code 128 和 Code 39，支持 PNG、矢量 PDF、打印、复制和批量 ZIP。业务数据不上传，组件不依赖外部 CDN。

[在线页面](https://xiaomai0974.github.io/xiaomai-gs1-barcode/)

## 码制与输入

通过“条码类型”下拉框切换，输入区域、示例、批量提示和输出设置随码制变化。

| 码制 | 输入 | 显示规则 |
| --- | --- | --- |
| GS1-128 | 整串 AI 内容或常用字段 | 一维码，可选 Arial 常规文字 |
| GS1 DataMatrix | 整串 AI 内容或常用字段 | 显式固定 format=square，宽高相等，不附下方文字 |
| EAN-13 | 12 或 13 位半角数字 | 固定显示首位、左六位、右六位及护栏，不提供独立高度或文字开关 |
| Code 128 | 可打印 ASCII 内容 | 自动选择编码字符集、计算内部校验字符，可选 Arial 常规文字 |
| Code 39 | 大写字母、数字和规定符号 | 自动添加起止符，可选 Arial 常规文字 |

EAN-13、Code 128 和 Code 39 不显示 GS1 字段。普通 Code 128 中的括号是普通字符，不解释为 AI，不自动加入 GS1 FNC1。当前界面支持 ASCII 32～126（半角数字、英文字母、空格及可打印符号），不提供控制字符和扩展字符输入模式。Code 128 保留首尾及行内空格、大小写，不做自动替换。

## GS1 输入规则

页面保留原有 7 个字段：01 GTIN、11 生产日期、17 失效期、10 批号、21 序列号、30 数量、37 件数。更多不常用 AI 直接写入整串，不增加独立输入框。

```text
(01)06972621148642(17)310514(10)LOT001
(01)06972621148642(15)310500(240)MODEL-A
(00)106141411234567897(02)06972621148642(37)12
```

- AI 编号为 2～4 位半角数字，使用英文半角括号 ()。中文括号会自动转换，全角数字不转换。
- 整串有内容时优先使用整串；清空后才使用下方字段。整串保留输入顺序；按字段填写时按 01、11、17、10、30、37、21 排列。
- 每个已输入的 AI 必须有内容。去除字段首尾空白；不允许括号、中文、换行或手工分隔控制符；具体字符、长度由 AI 定义决定。
- 01 GTIN / 02 内含商品 GTIN 为 14 位，00 SSCC 为 18 位，检查相应校验位。
- 10 批号和 21 序列号最多 20 字符；30 数量和 37 件数最多 8 位数字，保留前导零。
- 日期输出 YYMMDD，兼容 YYYYMMDD、YYYY-MM-DD 并转换；检查月份、天数和闰年。仅按该 AI 定义接受 00 日，表示该月最后一天。
- 启用引擎严格检查（dontlint=false、lintreqs=true），覆盖未知 AI、数据类型、长度、校验位、日期、必需关联和互斥关系。
- 日期、批号、件数等不能任意单独使用。例如 (17)310514、(37)12 会提示缺少关联字段。
- FNC1 和变长字段的分隔由引擎自动处理；阅读用的括号不作为普通括号编码。

更多支持字段示例：

| AI | 内容 |
| --- | --- |
| 00 / 02 | SSCC / 内含商品 GTIN |
| 13 / 15 / 16 | 包装日期 / 最佳食用期 / 最后销售日期 |
| 20 | 产品变体 |
| 240 / 241 / 242 | 附加产品标识 / 客户零件编号 / 按订单制造变体编号 |
| 250 / 251 | 附加序列号 / 源实体参考；250 还需要相应主标识和 21 序列号 |
| 400 | 客户采购订单号 |
| 410～417 / 422 | 各类位置 GLN / 原产国代码 |
| 310n | 净重 kg，例如 (3103)001250 表示 1.250 kg |

其他 AI 按内置引擎的定义校验。当前捆绑 bwip-js 4.11.2（2026-07-01）、BWIPP 2026-05-28；不把未识别的未来 AI 直接放行。

## EAN-13 校验

- 只接受 12 或 13 位半角数字，不接受 AI 括号、内部空格、字母或全角数字。
- 12 位自动计算第 13 位；13 位验证已有校验位，错误时提示应有的数字，不静默替换。
- 预览、复制内容和批量清单使用最终完整的 13 位。例如 400638133393 自动补齐为 4006381333931。
- 使用编码器原生数字分组、OCR-B 数字、护栏及比例，不套用 GS1-128 的整行文字。
- 开放条码高度和“显示下方数字”选项，默认高度参数 25.4 mm（与原编码器默认值一致），默认显示数字。隐藏数字适用于后续排版，正式商品包装须补上对应数字。

## Code 39 规则

新增的是标准 Code 39，不是 Code 39 Extended。

- 允许半角大写字母 A–Z、数字 0–9、空格和 `- . $ / + %`；不允许小写字母、中文、全角字符、括号、下划线等其他符号。
- 不自动转换大小写或删除空格，避免改变输入的编号；空白内容不能生成。
- 不要输入星号 `*`，编码器自动加入起止符。显示下方文字时使用 `*内容*`；扫码、复制及批量编码清单中的内容不带起止星号。
- 可选的 Mod 43 校验字符默认不添加，本版本未提供切换开关；不会把输入的最后一个字符当校验字符删除。
- 支持单个、每行一条批量、PNG、矢量 PDF、ZIP、打印和 1×～5× 倍率；默认纯黑、白底、Arial 常规文字。
- 输入示例：`XM-20261022-001`、`CODE39/ABC+123`、`LOT 2026-A.01`。

## 输出设置

- 所有码制默认纯黑 #000000、白底。清空后恢复纯黑和默认 3×。
- 清晰度 1×～5×，已有结果时切换立即重新生成。高度、颜色和文字开关变更后也自动更新已有结果。
- GS1-128、Code 128 和 Code 39 高度默认 15 mm，EAN-13 默认 25.4 mm；四者高度均可在 8～80 mm 内调整，支持小数。DataMatrix 不使用此设置。切换码制后恢复各自的高度；清空后恢复默认值。
- 倍率同时影响 PNG 像素及 PDF 导入尺寸，不是只修改 DPI。界面高度是编码器参数，正式排版的最终物理尺寸仍需按使用场景确定。
- PNG/PDF 共享白色扫描留白：GS1-128、Code 128 和 Code 39 左右至少 10 个模块，DataMatrix 四周至少 1 个模块，EAN-13 左右另留 11 / 7 个模块的白边。
- PDF 带白色底板，条码保持矢量，线性条纹为无描边填充矩形；条纹尺寸与同倍率 PNG 对应，页面自适配。文字及边界取整可能造成不足数个点的文件总尺寸差异。
- GS1-128、Code 128 和 Code 39 文字使用 Arial 常规、居中、过长缩小；EAN-13 使用原生 OCR-B 数字分组。
- 修改内容、切换码制或校验失败后清除旧下载结果，避免将旧码误当作新内容。
- 放进 Illustrator 后请等比例缩放，保留留白。

## 批量

五种码制均支持每行一条，一次最多 100 条非空行。Code 128 和 Code 39 保留每行首尾和行内空格；其他码制去除整行首尾空白。不同码制的批量输入只暂存在当前页面，切换后恢复，不写入持久存储。

错误行提示原始行号、输入和原因，正确行继续生成；全部失败不提供下载。PDF 或 PNG 打包为 ZIP，附编码清单.txt，每条一个文件。开始打包时固定本次结果，期间编辑输入不改变正在导出的文件集合。

## 本地运行与检查

纯静态网站，可使用静态文件服务器，例如在项目根目录执行：

```text
python -m http.server 4174
```

打开 http://127.0.0.1:4174/。规则回归测试使用 Node.js 内置测试框架，无需安装额外依赖：

```text
node --test tests/barcode-rules.test.cjs
```

规则参考：[GS1 官方 AI 定义](https://ref.gs1.org/ai/)、[GS1 语法字典](https://github.com/gs1/gs1-syntax-dictionary)、[BWIPP EAN-13](https://github.com/bwipp/postscriptbarcode/wiki/EAN-13)、[BWIPP Code 128](https://github.com/bwipp/postscriptbarcode/wiki/Code-128)、[BWIPP Code 39](https://github.com/bwipp/postscriptbarcode/wiki/Code-39)。编码检查不代替实际印刷尺寸与识读质量验证，正式使用前请用实际设备检查。
